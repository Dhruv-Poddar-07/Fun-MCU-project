## ⚡ What is this?

A scroll-driven, interaction-heavy tribute to the MCU — built to push what a portfolio project can feel like. No boring cards, no lazy fades. Every section fights for your attention the way the Avengers fight Thanos.

> Scratch it. Tilt it. Break it. Assemble it.

---

## 🎬 The Experience

| Section | What happens |
|---|---|
| 🎥 **Hero** | Scratch away the darkness to reveal the story underneath |
| 🕰️ **Timeline** | Six phases of the MCU, tilting and unfolding as you explore |
| 🦸 **Heroes** | 3D-popping hero cards with full stat reveals — sound included |
| 💎 **Infinity Stones** | Click to collect. Each one shatters into being |
| 💀 **Villains** | Corrupted, glitched, dangerous — click to breach |
| ✨ **Closing** | Particles assemble into a name — chase it with your cursor |

---

## 🛠️ Built With

- **React** — component architecture
- **Framer Motion** — every animation, gesture, and transition
- **Canvas API** — scratch reveal, magnetic cursor, particle physics
- **Tailwind CSS** — styling system
- **Vite** — build tooling

## 🚀 Run it yourself

```bash
git clone https://github.com/Dhruv-Poddar-07/Fun-MCU-project.git
cd Fun-MCU-project
npm install
npm run dev
```
